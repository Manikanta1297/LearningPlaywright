# LearningPlaywright

Playwright examples and exercises used for learning Playwright.js.

## Repository structure

- Chapter_01_Basic/: simple example scripts
- Chapter_02_Java_Concepts/: placeholder files for Java concepts

## Prerequisites

- Node.js (16+ recommended)
- npm

## Setup (JavaScript / Playwright)

1. Initialize project (if you plan to run tests):

```bash
npm init -y
npm install -D @playwright/test
npx playwright install
```

2. Run Playwright tests (if added):

```bash
npx playwright test
```

## Notes

- This repo currently contains example JS files and a Java chapter placeholder.
- Add tests under a `tests/` or `playwright` folder and update `package.json` scripts as needed.
